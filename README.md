# Reportly

**Reportly** est une application de bureau pour **rédiger, suivre et évaluer des rapports d'événements** au sein d'une équipe, dans un cadre professionnel.

Chaque équipe dispose de sa propre **structure** : les rapports d'une structure ne sont jamais visibles par une autre.

## Ce qu'elle permet

- **Rédiger un rapport** au moment d'un événement : date, personne concernée, type d'événement, catégorie, description.
- **Suivre dans le temps** : ajouter autant de suivis que nécessaire, puis clôturer avec une évaluation de l'effet obtenu.
- **Ne rien oublier** : rappels de suivi, rapports en retard signalés, suivi assigné à une personne précise.
- **Piloter l'activité** : tableau de bord, fiche par personne, calendrier des rappels.
- **Exporter** : rapport en PDF, synthèse mensuelle en PDF, export Excel du mois.
- **Échanger** : messagerie interne et commentaires sur chaque rapport.
- **Demander de l'aide** : le responsable peut solliciter l'administrateur central, et décide lui-même de lui donner ou non l'accès aux rapports.
- **Rester en sécurité** : connexion par code PIN personnel, déconnexion automatique après inactivité, historique des modifications.
- **Sauvegarder** ses données, y compris automatiquement chaque semaine.

Trois niveaux d'utilisateurs : **employé**, **responsable de structure** et **administrateur central**.

## Installer l'application

1. Ouvrez l'onglet **Releases** de ce dépôt.
2. Téléchargez le fichier d'installation de la dernière version.
3. Lancez-le, puis connectez-vous avec l'email et le code PIN que le responsable de votre structure vous a communiqués.

L'application se **met à jour automatiquement**.
